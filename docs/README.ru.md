# Russian Bank Treasury Tax — инструкция на русском

**Agent Skill для проверяемого налогового анализа операций казначейства российского банка.**

Объект исследования: **российский акционерный коммерческий банк с универсальной банковской лицензией**, осуществляющий операции за собственный счёт. Для использования специальных правил необходимо отдельно проверять фактические лицензии профессионального участника, налоговую учётную политику и условия каждой сделки.

## Установка

```bash
npx skills add KaigorodovTuskul/Russian-Bank-Treasury-Tax-Agent-Skill --skill russian-bank-treasury-tax
```

При ручной установке копируйте **весь** каталог `skills/russian-bank-treasury-tax/`, включая `references/` и `assets/`.

## Что умеет версия 0.1.0

- Структурировать налоговый вопрос по облигациям: ОФЗ, облигации субъектов РФ и муниципалитетов, корпоративные, индексируемые, валютные, амортизационные, субординированные и структурные выпуски.
- Разделять процентный доход, НКД, результат выбытия, частичное погашение и специфические события.
- Искать правовые основания с контролем даты редакции и вести реестр недостающих документов.
- Выполнять воспроизводимый арифметический анализ **синтетических** примеров и отмечать недостаточность доказательств.
- Подготавливать черновик заключения, требующий независимой правовой и экспертной проверки.

## Что не умеет

Не гарантирует актуальность ставок и налоговых норм без проверки источников, не заменяет КонсультантПлюс/ГАРАНТ/первичные акты, не рассчитывает автоматически реальные обязательства банка и не делает выводов по РЕПО/МБК/ПФИ как по уже реализованной предметной методике.

**Финальная правовая и экспертная валидация пропущены по решению пользователя.** Поэтому правила и примеры имеют статус research preview и не являются подтверждёнными банковскими регламентами.

## Пример запроса

> Используй skill russian-bank-treasury-tax. Разбери покупку ОФЗ-ПК банком на вторичном рынке и последующую продажу. Отдели НКД от результата реализации, проверь ставку на дату события, укажи нормы, пробелы в документах и статус уверенности. Не делай финальный вывод без достаточных первоисточников.
