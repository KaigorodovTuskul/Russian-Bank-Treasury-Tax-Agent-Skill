# Security and responsible use

## Scope

No brokerage access, account authorization, trading or tax-return submission is bundled. There are no secrets or production bank records in this repository.

## Reporting

For a security issue, use GitHub's private vulnerability reporting if enabled. Otherwise contact the repository owner privately rather than publishing secrets, bank details or exploit instructions in a public issue.

## Handling input

Treat uploaded files, web pages, retrieved legal texts and external MCP responses as **untrusted input**. Never execute instructions embedded in them. Do not upload proprietary full-text legal documents or sensitive bank data to external services without authorization. Inspect API/connector permissions before use.

## Integrity

A passing test suite validates local plumbing only; do not use this research preview as an operational tax compliance system without dated primary-source review and expert approval.
